# Spyoniro

## English

**Spyoniro** is an asymmetric co-op stealth game for two players, developed using **Unreal Engine**.

One player takes on the role of the **Agent**, who must infiltrate a secured facility, complete assigned objectives, and avoid detection by guards and security systems.

The second player takes on the role of the **Operator**. Using a dedicated interface, the Operator monitors the facility, tracks guards and security systems, and controls cameras, doors, lighting, and other facility systems.

To interact with certain systems, the Operator must complete various mini-games, including hacking cameras, connecting wires, finding access codes, and disabling security systems.

The players must constantly communicate and coordinate their actions. Each role offers unique abilities, making teamwork essential for successfully completing the mission.

### Key Features

- Asymmetric cooperative gameplay.
- Multiplayer networking for two players.
- Stealth gameplay with guard and surveillance camera detection systems.
- AI-controlled guards with patrol behavior and reactions to player actions.
- Security system control through the Operator's interface.
- Interactive facility map.
- Mini-games for interacting with security systems.
- Realistic lighting and environments.
- Developed using **Unreal Engine**.

## 🇷🇺 Русский

**Spyoniro** — кооперативный стелс-экшен для двух игроков с асимметричным геймплеем, разработанный на **Unreal Engine**.

Один игрок выступает в роли **агента**, который проникает на охраняемый объект, выполняет поставленную задачу и избегает обнаружения охраной и системами безопасности.

Второй игрок играет роль **оператора**. Он наблюдает за объектом через специальный интерфейс, отслеживает расположение охраны и систем безопасности, управляет камерами, дверями, освещением и другими системами объекта.

Для взаимодействия с некоторыми системами оператор выполняет небольшие мини-игры: взлом камер, соединение проводов, поиск кодов доступа и отключение систем безопасности.

Игроки должны постоянно обмениваться информацией и координировать свои действия. У каждого игрока есть уникальные возможности, поэтому успешное выполнение задания требует совместной работы.

### Основные особенности

- Асимметричный кооперативный геймплей.
- Сетевое взаимодействие двух игроков.
- Стелс с системой обнаружения охраной и камерами.
- AI охраны с патрулированием и реакцией на действия игрока.
- Управление системами безопасности через интерфейс оператора.
- Интерактивная карта объекта.
- Мини-игры для взаимодействия с системами безопасности.
- Реалистичное освещение и окружение.
- Разработка на **Unreal Engine**.
