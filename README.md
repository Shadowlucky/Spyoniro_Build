# Spyoniro

**Spyoniro** — кооперативный стелс-экшен для двух игроков с асимметричным геймплеем, разработанный на **Unreal Engine**.

Один игрок выступает в роли **агента**, который проникает на охраняемый объект, выполняет поставленную задачу и избегает обнаружения охраной и системами безопасности.

Второй игрок играет роль **оператора**. Он наблюдает за объектом через специальный интерфейс, отслеживает расположение охраны и систем безопасности, управляет камерами, дверями, освещением и другими системами объекта.

Для взаимодействия с некоторыми системами оператор выполняет небольшие мини-игры: взлом камер, соединение проводов, поиск кодов доступа и отключение систем безопасности.

Игроки должны постоянно обмениваться информацией и координировать свои действия. У каждого игрока есть уникальные возможности, поэтому успешное выполнение задания требует совместной работы.

## Основные особенности

- Асимметричный кооперативный геймплей.
- Сетевое взаимодействие двух игроков.
- Стелс с системой обнаружения охраной и камерами.
- AI охраны с патрулированием и реакцией на действия игрока.
- Управление системами безопасности через интерфейс оператора.
- Интерактивная карта объекта.
- Мини-игры для взаимодействия с системами безопасности.
- Реалистичное освещение и окружение.
- Разработка на **Unreal Engine**.
